# 通知背景写入与材质恢复

本文说明当前背景控制器的职责与边界。功能入口和最终支持范围见[1.8.3更新日志](RELEASE-1.8.3.zh-CN.md)，公开检查方法见[验证说明](../VALIDATION.md)。早期方案中的个人配置快照和私有排查记录不随源码分发。

## 控制器职责

- `FluidCloudAccent` 接收原生媒体主色并处理独立媒体强调色。
- `FluidCloudStyle` 按当前场景、业务范围和独立配置决定颜色、透明度及过渡。
- `FluidCloudSceneMaterial` 处理已核对原生背景的材质接入、背景换绑及恢复。
- `C17HighlightRemoval` 管理对应的光学高光与通知外观；它不改变媒体播放、通知内容或原生触摸对象。

独立媒体强调色、跟随媒体色和自定义底色分别保存。锁屏与 AOD 使用各自配置，普通通知的跟随强度也单独处理。关闭某个范围时归还该范围的原生背景，不删除用户参数，也不替其他页面开启功能。

## 颜色、透明度和动画

原生渐变的 RGB 与 Alpha 分开处理。明确选择自定义底色时，实际可见渐变使用所选 RGB；渐变透明度和底层材质透明度各自应用，避免重复叠乘。未编辑的原生默认配方保持原样。

背景对象或尺寸变化后重新确认当前宿主与原生基线，避免把旧背景、旧媒体色或旧动画终点带到复用卡片。退出、关闭、安全模式和运行时释放时归还本模块拥有的属性；未知材质或不匹配的接口保留原生。

## 公开验证边界

`FluidCloudPriorityCheck`、`FluidCloudScopeMaterialCheck`、`FluidCloudNativeGradientCheck`、`FluidCloudAodFollowCheck` 等检查覆盖颜色决策、范围独立、原生默认保持及恢复。它们是生产类的桌面回归，不代替设备的 GPU 合成、OEM 动画、全部业务卡片或耗电验收。

源码不包含原始 OEM APK、通知内容、手机偏好、截图或私有日志；复核公开实现无需取得开发者的设备备份。
