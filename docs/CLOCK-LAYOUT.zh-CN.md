# 状态栏时间：默认时钟、双排时钟、等宽数字与整体边距

> **code96 更新**：新增“冒号居中”（状态栏时间、下拉时间、经典面板时间各一个开关，默认开）。多数字体把冒号画在小写字母的高度，放在等高的数字旁就显得偏低。现在时间文字里的冒号（`:` 与全角 `：`）按数字墨迹的中线重画：量出“0”和“:”各自的墨迹上下边，把冒号上移两者中线的差（最多四分之一字号；字体本来就居中的，差值不足半个像素，不动）。与等宽数字互不依赖（含秒或不含秒都生效）；双排时钟的两排同样处理。锁屏大时钟（`NotificationBigClock` 的自绘时间）也做同样处理，那里没有单独开关。冒号用 `ReplacementSpan` 重画，宽度取整到像素，对排版的影响不超过半个像素。

> **code95 更新**：状态栏是固定高度，单行时钟的行高超过它时下半截会被裁掉。现在单行时钟保持所设大小，只要行高放得下；放不下时缩到放得下的最大字号（`TextControls.fitHeight`，以时钟视图的实际高度为准，首次布局后会再量一次）。双排时钟不受影响。

> **code94 更新**：所有时间类“格式”输入框（状态栏时间、双排上下排、大时钟时间/日期/底部内容、锁屏日期、运营商面板时间、经典面板时间等）上方新增“预设”芯片，点一下把对应格式填进输入框；预设来自该字段原来的“常用格式”列表，没有列表的字段用一组通用写法。预览与保存前检查照常生效。

> **code93 更新**：默认时钟（单排）与双排时钟二选一，两个都保存为开时以单排为准（旧版本允许同时为开）；打开本页时检测到这种状态会把双排开关保存为关。想用双排，在“双排时钟”标签里打开它，会自动关闭默认时钟。时间格式的可用字段表已按实际支持的写法核对（含 {时段} 的取值、{农历日期}、{文本}、E/EEEE 等），时间类设置补了一句话说明。

入口：**配置 → 状态栏 → 状态栏时间**。页面顶部有两个标签：

- **默认时钟**：原来的单行时钟，设置时间格式、位置、大小、字距、颜色和“等宽数字”。标签顶部有“启用默认时钟”开关。
- **双排时钟**：另一种显示，时间分上下两排。标签顶部有“启用双排时钟”开关。它**独立于默认时钟**：不需要打开默认时钟的开关，开启后直接接管状态栏时间；内容、大小、粗细、位置、颜色、整体边距都在这一页单独设置，不与默认时钟共用。

两种显示**二选一**：开启其中一个，同一次保存里自动关闭另一个（开双排关默认，开默认关双排）；两个都关则是系统原样。导入的配置里如果两个都是开，双排优先。

## 1. 等宽数字（秒数不再跳动）

时钟显示秒时，间距会左右抖动：大多数字体里数字宽度不一样（“1”比“0”窄），秒数每变一次整行宽度就变一次。

- 开启“等宽数字（防秒数跳动）”后，每个数字（ASCII 0–9）都占一个同样宽的格子，宽度取**当前实际绘制字体**里最宽的那个数字，数字在格子里居中；冒号、汉字等其他字符不变。
- “数字间距”（-2 到 8 dp）是每个数字格额外增加（或减少）的宽度，用来统一调整数字之间的松紧。
- 只在时间格式**含秒**时生效，不含秒的格式保持系统原有数字宽度，外观与升级前一致。默认开启。双排时钟的上下两排都适用。
- 状态栏时间、通知栏与控制中心时钟、经典模式时间各有一组开关，互不影响。
- 实现：给每个数字挂一个 `ReplacementSpan`，格宽按画笔的字号、字体、变体轴和字距缓存，字体或大小变化才重新测量；时钟测量改用包含 span 的宽度，所以右侧图标的让位也跟着稳定。无障碍读出的文字是纯文本，不带 span。

## 2. 双排时钟

状态栏时间分上下两排显示（仅状态栏原生时钟，其他位置的时钟保持单排）。

| 分区 | 设置 | 说明 |
|------|------|------|
| 内容 | 双排时钟（页面开关） | 开启后接管状态栏时间。 |
| 内容 | 上排内容 / 下排内容 | 使用与时间格式相同的格式语法：时分秒、日期、星期、农历、中文时段，也可输入自定义格式。默认上排“时分”、下排“月日 星期”。 |
| 大小 | 上排大小 / 下排大小 | 相对系统原生时钟字号的百分比，默认 72% / 56%。 |
| 文字样式 | 上排粗细 / 下排粗细 | 100–900，默认 600 / 500。 |
| 文字样式 | 字距微调 | 双排自己的字距，-2 到 8 dp。 |
| 位置 | 水平位置 / 垂直位置 | 整个时间块的偏移，-80 到 80 dp / -24 到 24 dp，只移动绘制。 |
| 位置 | 两排间距 | 两排之间的额外距离，可为负，默认 0。 |
| 位置 | 两排对齐 | 居中 / 靠左 / 靠右，以较宽的一排为准。 |
| 整体边距 | 整体边距、左边距、右边距 | 见第 3 节。 |
| 颜色与透明度 | 自定义颜色、时间文字（浅色/深色背景） | 默认关闭，沿用系统随背景变化的原生颜色；开启后按浅色、深色背景分别设置，可带透明度。 |

实现要点：

- 系统的时钟视图继续负责上排，测量、字体、颜色和系统 Hook 都保持原样；下排是模块自己持有的一行 `StaticLayout`，只在文字或样式变化时（最多每秒一次）重建，绘制时直接画出。
- 上下两排作为一个整体在时钟视图内垂直居中，水平方向按“两排对齐”排布。时钟宽度取较宽一排加上左右边距。
- 双排不要求同时开启“自定义时间格式”，它只接管状态栏原生时钟，不会改动锁屏、下拉页等位置的时钟文字。
- 下排含秒时每秒刷新；下排宽度变化超过 0.5 px 才请求重新布局。
- 双排的上排大小替代默认时钟的“文字大小”，双排的颜色替代默认时钟的“时间文字”颜色，互不共用。

限制：两排总高度需要放得进状态栏里时钟的高度。默认大小可以放下；调得过大或两排间距过大时，下排可能被裁切，请减小大小或间距。

## 3. 整体边距

“整体边距”属于双排时钟，在“双排时钟”页里打开后可分别设置左边距、右边距（0–40 dp）。

- 时钟视图的占位宽度增加左右边距，相邻图标随之让开；时间内容绘制在留白内，位置不变。
- 与“水平位置/垂直位置”叠加：边距改变占位宽度，偏移只移动绘制。
- 默认时钟没有整体边距；只改变默认时钟不会带来留白。

## 4. 设置、迁移与兼容

- 键都在 `ClockLayoutSettings` 登记。schema 13 的 18 个键：三组数字对齐（各 1 个开关和 1 个间距，共 6 个）、双排 9 个（1 个开关、2 个格式、2 个大小、2 个粗细、1 个间距、1 个对齐）、整体边距 3 个（1 个开关和 2 个数值）。schema 14 的 `Upgrade91` 共 13 个键，其中时钟 8 个：水平/垂直位置、字距微调、自定义颜色开关，以及浅色/深色时间文字颜色及各自的透明度标记；其余 5 个属于流体云（三个作用场景开关、通知跟随媒体色的开关与强度）。
- 框架副本升到 schema 14，旧 schema 副本补齐默认值；已含新键的旧 schema 副本视为不完整写入，保持原有严格校验。导入导出、恢复默认、诊断报告都按已有机制覆盖新键，对齐方式导入时校验取值。
- 等宽数字默认开启但只对含秒格式生效；双排和整体边距默认关闭。已有配置不会因升级改变外观，除非原来就在显示秒。
- 双排的“自定义颜色”默认关闭，所以升级后双排的颜色仍与原生一致。

## 5. 秒数停摆的保护（code91）

秒数由模块自己的定时器每秒刷新（系统原生时钟只每分钟更新一次）。实机反馈过“秒数偶尔停住，触摸后才恢复”，当时没有拿到日志，**根因没有确认**；这一版把所有能想到的、会让定时器链静默中断的路径都堵上，并加上自动补救：

- 每次定时器触发后，无论刷新过程提前返回（处于原生样式作用域内）还是某个位置出错，都会重新安排下一次。
- 一个位置刷新失败不再影响其他位置的时钟。
- 定时器如果晚了 3 秒以上仍没有执行，视为丢失，清掉并重建。
- 漏收“亮屏”广播时，以 `PowerManager` 的真实状态为准（限频，最多每 0.5 秒查询一次）。
- 系统自己每分钟更新时钟文字、以及时钟被绘制时，都会顺带检查并补回丢失的定时器。
- 开启诊断日志后，每次补救都会记一条 `clock` 事实（`reason` 为 `pending_lost`、`screen_on_missed` 或 `draw_without_tick`，附停顿时长），导出的问题报告里的“诊断”会出现“时钟的秒数刷新停过并已自动恢复”。**这样下次卡住时可以直接看出是哪条路径。**

## 6. 验证范围

桌面检查覆盖：默认值与注册、迁移与导入导出、设置页依赖提示、双排几何计算（居中、靠左、靠右、间距、负宽度保护）、数字格宽度（比例字体下不同秒数宽度一致、间距加减、随字号和字距变化）、整体边距只作用于双排、双排独立于默认时钟开关，以及定时器在作用域内触发、单个位置失败、定时器丢失、漏收亮屏广播、绘制时补救和隐藏时不计时等情形；既有时钟测量、字号和文字检查在新逻辑下保持通过。

**没有在手机上验证**：真实 StatClock 内的双排绘制位置与裁切、字体变体轴下的格宽、不同系统字体的观感、整体边距在真实状态栏里对相邻图标的让位，以及秒数停摆是否确实消失，都需要实机确认。逐项见包旁“检查清单.txt”。
