# 左右组件内容格式（类别:模板）

适用于竖屏大时钟的左、右文字组件（配置 → 通知栏 → 左右组件 → 组件内容）。天气、电池、信号、网络四类可以像时间格式一样自定义：**文字和 `{字段}` 混排，符号完全由你自己写**。原有的 `（天气）`、`（电池）`、`（蜂窝信号）`、`（网络状态）` 等写法继续有效，设置页里也保留。

## 写法

```
（类别:模板）
```

类别：`天气`、`电池`、`信号`（也可写 `蜂窝信号`）、`网络`（也可写 `网络状态`）。冒号中英文均可，括号中英文均可。模板里没有任何 `{字段}` 时，整段按普通文字原样显示（例如 `（电池：满格）`）。

| 写法 | 含义 |
| --- | --- |
| `{字段}` | 显示字段的值 |
| `{字段:参数}` | 带参数，多个参数用 `:` 隔开，如 `{条:5:█:░}` |
| `{字段?有时显示}` | 字段有值（文字非空、数字存在、条件成立）时显示 |
| `{字段?有时显示\|没有时显示}` | 加上“否则”部分；两部分里都可以再写 `{字段}` 和条件 |
| `{电量<=20?低\|够}` | 数字字段可以比较：`<` `<=` `>` `>=` `=` `!=` |
| `'…'` | 单引号里的内容原样显示，可放 `{ } \| ( ) :` 等符号；`''` 表示一个单引号 |

模板之外的文字不会被解释，写 `电量{电量}` 就是原样显示这几个字。

## 字段

### 天气

| 字段 | 说明 |
| --- | --- |
| `{描述}` `{描述:中文}` `{描述:英文}` `{描述:系统}` | 天气文字，默认跟随系统语言；中英文只改文字，不联网翻译 |
| `{温度}` `{温度:数字}` `{温度:单位}` | `23°`、`23`、`°`；温度可比较，如 `{温度<10?冷\|暖}` |
| `{图标}` `{图标:原色}` | 模块按系统天气码及日出日落选择的天气图标，不依赖锁屏天气小部件；默认随文字颜色，`原色` 使用模块天气图案的独立配色 |
| `{夜}` `{昼}` `{有数据}` `{有温度}` | 条件，如 `{夜?🌙\|☀️}` |

### 电池

| 字段 | 说明 |
| --- | --- |
| `{电量}` `{电量:000}` | 0 到 100；冒号后写 `0` 的个数是补零位数（`085`） |
| `{状态}` `{状态:英文}` | 充电中 / 已充满 / 未充电 / 充电状态未知（放电时为空） |
| `{条:格数:实心:空心}` | 文字电量条，格数 1 到 20，默认 `10:█:░`；实心、空心符号自己写 |
| `{图标}` | 状态栏样式的电池图标 |
| `{充电}` `{满电}` `{未充电}` `{放电}` `{状态未知}` `{低电}` `{有数据}` | 条件；`低电` 指 20% 及以下 |

### 信号

| 字段 | 说明 |
| --- | --- |
| `{格数}` `{总格}` | 0 到 4 / 固定 4；格数可比较 |
| `{状态}` `{状态:英文}` | 飞行模式 / 无SIM卡 / 无服务（正常时为空） |
| `{条:总格:实心:空心}` | 如 `{条:4:●:○}`，总格 1 到 8，默认 `4:●:○` |
| `{图标}` | 单卡或双卡的状态栏样式信号图标 |
| `{飞行}` `{无卡}` `{无服务}` `{有信号}` `{有数据}` | 条件 |

### 网络

| 字段 | 说明 |
| --- | --- |
| `{类型}` `{类型:英文}` | Wi-Fi / 5G 等制式或蜂窝网络 / 以太网 / 其他网络 / 未联网 |
| `{制式}` | 蜂窝时的 5G、4G 等，其他情况为空 |
| `{状态}` `{状态:英文}` | 受限 / 联网状态未知（正常时为空） |
| `{WiFi格数}` `{条:总格:实心:空心}` | Wi-Fi 信号格数 / 文字信号点，非 Wi-Fi 时为空 |
| `{图标}` | 当前连接方式的状态栏样式图标 |
| `{联网}` `{WiFi}` `{蜂窝}` `{有线}` `{离线}` `{受限}` `{有数据}` | 条件 |

## 没有数据时

整段 `（类别:…）` 显示该类别的提示（天气暂无数据、电池暂无数据、蜂窝信号暂无数据、网络暂无数据），不会写出空的单位符号。想自己写提示，就在模板里用 `{有数据?…|…}`，例如 `（电池:{有数据?{电量}%|--}）`。

## 示例

| 模板 | 结果 |
| --- | --- |
| `（电池:{电量}%{充电?⚡}）` | `85%⚡` |
| `（电池:{条:5:█:░} {电量}%）` | `████░ 85%` |
| `（电池:{电量<=20?🪫\|🔋} {电量}%）` | `🔋 85%` |
| `（天气:{描述} {温度:数字}°C）` | `多云 23°C` |
| `（天气:{夜?🌙\|☀️} {温度}）` | `☀️ 23°` |
| `（信号:{条:4:●:○}）` | `●●●○` |
| `（网络:{类型}{受限?'（受限）'}）` | `Wi-Fi`，受限时 `Wi-Fi（受限）` |
| `（网络:{制式?{制式}\|{类型}}）` | 蜂窝时 `5G`，否则 `Wi-Fi` |
| `（电池:{电量}%） · （网络:{类型}）` | `85% · Wi-Fi` |

## 保存和检查

- 模板里写错字段、参数、括号或单引号，预览会直接显示原因，也不能保存；不会在通知页组件里显示成乱码。
- 最多 240 个字符，单行。
- 设置页预览使用示例数据（多云 23°、电量 85% 充电中、信号 3 格、Wi-Fi）；实际组件使用系统当前数据。天气由模块按真实天气内容绘图，电池、信号和网络沿用实际状态栏图标来源。
- 左、右组件都可以使用全部四类。
