# 图标大小和图库颜色预设（beta98 / code191）

入口为“其他 → 图标管理”。在“自定义”中进入单项，开启“独立图标大小”后可调 25%–200%，100%为原大小；仅缩放图案，保持系统布局、位置和点击区域。系统提示可选浅色背景与深色背景颜色。快捷开关可分别编辑开启、关闭状态；图案来源与外观独立保存。

图库详情支持预览和应用颜色预设。先选择状态栏或控制中心等范围，再选预设；“仅应用颜色预设”不改变图案来源或每项大小，取消预览不落盘。旧版没有预设的 v3 包也提供“跟随系统颜色”和“保留素材原色”。

范围级预设会覆盖该范围已有的下级颜色模式，目标级预设会覆盖其已有的逐状态颜色；仍保留每项大小及未指定的透明度。只声明单个角色的预设只改变该角色，未选范围保持原样。

## 可选 v3 扩展

`manifest.json` 可新增 `colorPresets` 对象，不改变 `version: 3`。旧包无需增加该字段。旧版严格准入器不识别此扩展，因此发布者可同时提供去掉该字段的兼容包。

```json
{
  "colorPresets": {
    "blue": {
      "name": "蓝色开启 · 灰色关闭",
      "appearances": {
        "scope:tile": {
          "mode": "custom",
          "lightColor": -12829636,
          "darkColor": -6776675
        },
        "role:tile.wifi.on": {
          "mode": "custom",
          "lightColor": -16745729,
          "darkColor": -16087809
        }
      }
    }
  }
}
```

键须匹配 `[a-z0-9][a-z0-9_-]{0,63}`，最多16组，每组名称最多64字、包含1–256条已登记外观项。外观键为 `scope:<scope>`、`target:<target>` 或 `role:<role>`。允许 `mode` 为 `inherit`、`system`、`artwork`、`custom`；自定义色必须同时给出 `lightColor`、`darkColor`，使用不透明 signed 32-bit ARGB 整数；独立透明度使用可选的 `opacity`（0–100）。预设不允许携带 `sizePercent` 或图案来源。

用户自己的 `icon_management_v3_records.appearances` 可以保存可选的 `sizePercent`（25–200）；null表示继承，最终默认100。此字段与模式、RGB、透明度分别继承。双排信号保持共用画布，不能分别裁剪拉满。

RGB按系统当前前景亮度在两种背景颜色之间过渡，保留系统原生的深浅色动画；透明度保持独立。图标包的配色是可选测试外观，不代表 Apple 或 OEM 的官方取色规范。
