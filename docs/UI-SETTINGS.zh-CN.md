# 设置应用的界面设置

> **code96 更新**：“界面设置”新增“开源主题”：**Material 3**（Google 基线配色，浅色与深色各自的官方色值）和 **Catppuccin**（浅色 Latte、深色 Mocha，MIT）。主题使用原作的背景、卡片层级、文字、描边与错误色，只有主色的“禁用/变体”等派生状态由 Miuix 按主色补齐；选用后“色彩风格”置灰（不适用），“深浅色”和“深色背景”仍然有效。色值在 `UiThemes.kt`，来源与许可见根目录 `THIRD_PARTY_NOTICES.md`（Catppuccin 的 MIT 全文在 `docs/third-party/catppuccin-LICENSE-MIT.txt`）。分段控件选中项的文字改用主题的“主色上的文字”，浅色主色（如 Catppuccin Mocha）上不再是白字压白底。

> **code95 更新**：经典蓝在“柔和/鲜艳/素净”下保持原来的背景与文字，只有强调色随风格变化；系统取色选“鲜艳/素净”时由壁纸主色（`system_accent1_500`）按风格派生，“柔和”仍是系统调色板原样；拖动“深色背景”滑块或打开输入框时整个应用立即显示为深色（预览，不保存，松手后约 1.5 秒恢复）。

> **code94 更新**：关于页里“界面设置”与“检查更新”分成两张独立卡片；所有配色方案（含默认的经典蓝）都可以选“柔和 / 鲜艳 / 素净”，经典蓝按所选风格由基准蓝 `#3482FF` 派生；“界面字号”和“深色背景”的数值可以点击后直接输入（字号 80～130，深色背景 0～100），滑块仍可拖动；滚动渐隐最长由 28 dp 增至 33 dp。

> **code93 更新**：深浅色、色彩风格改为自绘的分段控件（圆角底槽加主题色实心滑块），不再使用页签控件；配色方案每行 5 个、等宽排开。

入口：**关于 → 界面设置**（独立页面，右侧显示当前配色方案）。这里的选项只改变本设置应用自己的样子，**不进入 SystemUI 配置**，所以不会被配置导出、导入、“删除所有配置”或安全模式影响，也不改变状态栏、通知栏的任何显示。存放在应用私有的 `app_ui` 偏好文件里（与液态玻璃底栏开关同一个文件）。

页面刻意只放一行一项，没有说明小字，和其他设置页的行样式一致。

| 设置 | 选项 |
|------|------|
| 深浅色 | 跟随系统 / 浅色 / 深色。跟随系统时随系统自动深色模式切换；系统栏图标明暗同步变化。 |
| 配色方案 | 经典蓝、系统取色、清新绿、落日橙、樱花粉、薰衣草、湖水青、午夜靛、珊瑚红、石墨灰。经典蓝是 Miuix 原版配色；系统取色跟随壁纸（Android 12+，不支持时置灰）；其余由主色推导整套调色板。 |
| 色彩风格 | 柔和 / 鲜艳 / 素净（经典蓝不受影响，置灰）。 |
| 深色背景 | 滑杆：偏左背景偏灰，中间为方案原色，偏右接近纯黑（OLED 省电）。只影响深色模式。 |
| 界面字号 | 80%–130%，只缩放本应用的文字。 |
| 滚动渐隐 | 默认开。列表向上滚动时，滚到顶部边缘之外的内容渐隐；渐隐长度随滚动距离增长，最长 33 dp，静止时完全不影响，没有需要调的参数。 |
| 液态玻璃底栏 | 原先在关于页顶部，现在并入这里（Android 13+，省电模式下不做实时模糊）。 |
| 恢复默认 | 只恢复上面的外观设置，不改动模块设置，也不改动底栏开关。 |

## 实现

- `UiSettings`：状态与读写，带范围校正，坏值回到默认；`ModernTheme.kt` 的 `C17Theme` 据此构造 Miuix 主题（`ThemeController` + 深色黑度微调 `tuneDark`），同步系统栏与窗口背景并缩放字号。
- `Modifier.edgeFade`：渐隐直接作用在列表本身，只在列表已经滚动时才建立离屏层，静止的列表没有额外开销。以前的“渐进模糊”选项（含强度、高度）已移除：它的区域放在列表顶部，列表静止时就会盖住第一张卡片。
- 开启诊断日志后，设置应用会记录一条 `ui` 事实（主题、方案、黑度、渐隐、底栏），出现在问题报告的 `latest_facts.ui`。

## 没有在手机上验证

这是 Compose 界面，桌面检查无法渲染：各配色方案与深色黑度的实际观感、渐隐的起止位置与长度、与顶部栏和液态玻璃底栏的叠放，都需要实机确认。
